# mitigations/

Remediation text, keyed by weakness class rather than by test.

Six cross-site scripting units and four DOM XSS units share one remediation text
about contextual output encoding. Written per unit it would be ten copies
diverging from the moment the second was written, so mitigation attaches to the
weakness and units reference it.

Text here is **originally written**. ASVS requirement identifiers are cited as
cross-references for report writing; no ASVS prose is copied.

One file so far: `path-resolution.md`, written alongside the topic that
referenced it. That is the intended order -- a mitigation is written when a unit
needs it, not speculatively, for the same reason a card is.
